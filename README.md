# Fundamental Concepts of Jiu Jitsu

A Mental Model for Every Stage of the Journey

<a href="https://www.amazon.com/Fundamental-Concepts-Jiu-Jitsu-Journey/dp/B0HNJGJ2Z5/"><img src="covers/Front%20Fundamental%20Concepts%20of%20Jiu%20Jitsu-frontcover.jpg" alt="Front cover of Fundamental Concepts of Jiu Jitsu" width="300"/></a>

This repository contains the source material for the book of the above title, available on [Amazon](https://www.amazon.com/Fundamental-Concepts-Jiu-Jitsu-Journey/dp/B0HNJGJ2Z5/).

This work is available as open source to allow the world to read, review, and contribute corrections to any factual inaccuracies or suggestions for items to cover in subsequent editions.  The goal of this book is to capture a mental model for the core positions in jiu jitsu and core concepts that underlay each and are nearly universally applicable.

## Repository Layout

- `markdown/`: the manuscript, one Markdown file per chapter. This is where corrections are made.
- `word/`: the Word manuscript used to produce the published edition.
- `covers/`: cover artwork, including the print-ready paperback and hardcover PDFs.
- `CHANGELOG.md`: changes made to the published edition.
- `ERRATA.md`: known errors in the published edition and their status.
- `CONTRIBUTING.md`: how to report an issue or submit a fix.

## Contributing

Feel free to file issues for inaccuracies found in the book, or even pull requests with fixes.  It is not my intent to expand this edition of this work with new content, however, there may be future editions where new content can be integrated.  Source material will be updated on [Amazon KDP](https://kdp.amazon.com) as bugfixes are integrated and inaccuracies are addressed.

See [CONTRIBUTING.md](CONTRIBUTING.md) for details.
